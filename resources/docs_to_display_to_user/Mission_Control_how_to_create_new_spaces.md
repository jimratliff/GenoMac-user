# How to create 15 new Mission Control Spaces

> [!NOTE]
> Don’t want to deal with this right this sec? Return to the terminal and enter 'punt'.
> This task will be re-presented to you next time you run the Hypervisor.

## Enter Mission Control
Either:
- ⌃⌥⌘F8, OR
- Swipe Up with Four Fingers

## Create 15 new Spaces
- For each new Space, click “⊕” (“+”) in the far right-hand side of what would be the menubar.
- Iteratively create new Spaces until you reach a total of 16.

## Return to the terminal
Now return to the terminal and acknowledge you have completed enabling the Witch preference pane.
