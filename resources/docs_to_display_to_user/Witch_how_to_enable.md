# How to enable the Witch preference pane

> [!NOTE]
> Don’t want to deal with this right this sec? Return to the terminal and enter 'punt'.
> This task will be re-presented to you next time you run the Hypervisor.

> [!TIP]
> This process uses *two* separate panes from System Settings:
> - The Witch pane itself
> - The System Settings » Privacy & Security » Device Control and Data Access pane
> 
> Hypervisor opens the Witch pane for you, and clicking on the “Open System Settings” button of a dialog box will open the Device Control and Data Access pane. **The only hitch** is that only one of the two panels can be open at the same time. So if you click the “Open System Settings” button first, it will replace the Witch panel, which you’ll then have to reopen manually.

## Make the Witch preference pane active
- ❑ Make the Witch preference pane active
  - The script will already have opened the Witch preference pane for you.
- Alternatively:
  - ❑ Open System Settings (⌘,)
  - ❑ At the bottom of the left sidebar, click on “Witch”

## Enable Witch
- ❑ Toggle ON the switch to “Enable Witch” in the upper-left corner of the right-hand pane of System Settings.
  - (In my experience, this has been ON by default, making this entire exercise pointless.)

## Give Witch permission to control this Mac and access your data
- You’ll see a **Device Control and Data Access** dialog box
  - “**‘witchdaemon.app’ would like to control this Mac and access your data.**”
    - “Grant access to this application in Privacy & Security settings, located in System Settings”
  - Click on the “Open System Settings” button.
  - This will open the System Settings » Privacy & Security » Device Control and Data Access pane.
    - witchdaemon.app will already appear as one of the rows
    - ❑ Change the toggle from ❌ → ✅

## Return to the terminal
Now return to the terminal and acknowledge you have completed enabling the Witch preference pane.
